# minecraft-integration

**Status: planned (Phase 5). Not started by design.**

This module will contain proximity calculations, player voice state, push-to-talk bindings, and loader-specific adapters.

It intentionally contains no source code yet. The milestone plan explicitly defers Minecraft integration until the Android audio foundation works, so no placeholder classes or stub methods are present.

See `docs/ARCHITECTURE.md` for the intended dependency rules and `docs/RESEARCH.md` for the interoperability boundary.
